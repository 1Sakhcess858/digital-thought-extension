# D.T.E. — Digital Thought Extension

A personal thinking system. Built to capture thoughts, remember why I started, and build a history of my own thinking over time.

This is **v0.1** — a personal prototype. Not a product. Not finished.

---

## Purpose

D.T.E. is not a notes app. It's not a chatbot. It's a quiet personal space for thinking.

The goal is simple:

> Does this genuinely improve the way I capture, remember, organise and develop my thinking?

---

## Features (v0.1)

| Feature | What It Does |
|---------|--------------|
| **Quick Capture** | Write a thought, idea, question, lesson, reflection, or goal |
| **Threads** | Group thoughts under a continuing theme |
| **Remember Why** | Store your personal WHY and see it on the dashboard |
| **Echoes** | Short user-created reminders you choose to see again |
| **Reflection** | A simple daily reflection prompt |
| **Goals** | Track goals with WHY, progress, and next action |
| **Future Me** | Write messages to your future self with an unlock date |
| **Dashboard** | Greeting, active thread, Echo, reflection, and Quick Capture |

---

## Technology

| Layer | Technology |
|-------|------------|
| Backend | Node.js + Express |
| Database | SQLite |
| Frontend | Plain HTML, CSS, JavaScript |
| AI | None (by design for v0.1) |

No frameworks. No build tools. Everything visible.
